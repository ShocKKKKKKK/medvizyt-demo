# Med-assistant

Статический сайт с PHP-обработчиком заявок через SMTP.

## Настройка отправки заявок

1. Откройте файл `config.php` в корне сайта.
2. Впишите SMTP-данные клиента:
   - `host` — адрес SMTP-сервера;
   - `port` — порт, обычно `587` для TLS или `465` для SSL;
   - `encryption` — `tls`, `ssl` или пустая строка, если шифрование отключено;
   - `username` — SMTP-логин;
   - `password` — SMTP-пароль или пароль приложения;
   - `from_email` — почта отправителя, разрешённая SMTP-сервером;
   - `from_name` — имя отправителя в письме.
3. Загрузите на хостинг весь проект, включая папку `vendor`.
4. После загрузки отправьте тестовую заявку с основной формы и из формы вопроса.

Каждая заявка отправляется одновременно на:

- `verbadianaka@gmail.com`;
- `mail@zayavkionline.com`.

Файл `config.php` добавлен в `.gitignore`, поэтому SMTP-пароль не попадёт в репозиторий. Для восстановления структуры настроек используйте `config.example.php`.

## Требования к хостингу

- PHP 7.4 или новее с расширениями `ctype`, `filter`, `hash`, `openssl` и `fileinfo`;
- доступ к внешнему SMTP-серверу;
- поддержка отправки запросов формы на `send.php`.

Локальный сервер на Python показывает страницы, но не исполняет PHP. Полную SMTP-отправку нужно проверять на PHP-хостинге или в локальном окружении с PHP.

## Защита форм

Обработчик проверяет обязательные поля и телефон, использует скрытое honeypot-поле, контролирует минимальное время заполнения и ограничивает частоту повторных заявок с одного IP-адреса.
